# Contributing

Thank you for helping shape System Verification Engineering.

## Sign the manifesto

Open a pull request that adds one line to `SIGNATORIES.md`:

```
- Your Name, Role, Organization
```

Keep entries in the order received. One line per person.

## Propose changes to the text

- **Substantive changes** (new ideas, reworded principles): open an issue first so others can discuss.
- **Small fixes** (typos, broken links): open a pull request directly.

Accepted changes are released as new versions and recorded in the README changelog. The PDF and `index.html` are updated together.

## Share practice

Methods, tools, team structures and career paths that make SVE work are welcome as issues.
